Artwork workflow

1. Copy the image prompt. 2. Generate one image per slot. 3. Connect the folder containing index.html, then upload. The manager saves the exact filename to its correct folder. Without folder access, it downloads a correctly named file.

Important: the sheet animation uses five PNG stages. Their alignment is controlled by style.css. Hoovering and desk tidying now use individual PNG artwork and interactive layers.
